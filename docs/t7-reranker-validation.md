# T7：Reranker 小样本验证（结论：不达标，不集成）

日期：2026-10-24 ｜ 版本：v0.1.24 索引（59,528 块 / 791 篇）
模型：`Xenova/bge-reranker-base` int8 ONNX（266 MB，CPU 6 线程 onnxruntime）

## 一、预注册的通过标准（动手前定死）

| 项 | 门槛 |
|---|---|
| 指标 | **R@5 ≥ +2.00pp 或 Hit@1 ≥ +5.00pp**（另一项不得倒退）|
| 延迟 | 热查询增量 **≤ 300ms** |
| 稳定性 | 75 条里明显变差 ≤ 3 条 |

## 二、方法（保证与官方评估同口径）

1. **导出官方 V0 候选**：用 `export_candidates.mjs` 复用 `core.js`（与 `02_eval.mjs` 完全相同的 BM25/dense/RRF k=60 融合），对 75 条金标各导出 top-200 块。
   - 自检：**R@5=90.67% / Hit@1=78.67% / MRR=0.8446**，与文档基线完全一致 → 候选集可信。
2. **Python 重排**：`bge-reranker-base` 对 (query, chunk) 打分；候选按 4 种方式重排：
   - `chunkN`：前 N 块按重排分降序；
   - `paperN`：文内取 max 分后按文献重排；
   - `blendN`：原序与重排按 RRF 融合（0.5/0.5, k0=60）。
3. **指标**：篇级 R@5 / Hit@1 / MRR@10（首次出现 gid 的秩，与官方 `metricsFor` 一致）。

## 五、结论：**不达标，不集成**

1. **指标未过线**：最好成绩 Hit@1 **+4.00pp**（门槛 +5.00pp）、R@5 **+1.33pp**（门槛 +2.00pp）——两项均差一点。
2. **延迟远超门槛**：即使只重排 top-10、截断 256 token，也要 **+0.85s/查询**（门槛 ≤300ms；当前热查询总共 0.22s，等于慢 5 倍）。
3. **稳定性**：8 条查询变差（门槛 ≤3 条）。

按预注册纪律：**记录结论、不实装**。reranker 理论上限受召回约束（7 条未命中里多数候选里根本没有目标），收益本就不大；实测也印证。

## 六、顺带发现一个真实 Bug（与 T7 无关，但影响更大）

**现象**：用插件真实接口 `/retrieval/search` 回放同一批 75 条金标，R@5 只有 **82.67%**（官方模拟 90.67%），19/75 条排序不同。

**根因**：`content/retrieval.js` 的查询后处理有个两轮循环：

```js
for (let pass = 1; pass <= 2; pass++) {
  for (const [i] of ranked) {
    if (out.length >= kk) break;        // ← 第一轮就填满 k 个名额
    if (pass === 1 && titlePoor(c.title)) continue;  // ← 低信息标题第一轮全跳过
    ...
  }
}
```

- `titlePoor()` = `cleanTitle` 后「汉字 < 4 且字母 < 12」；
- 第一轮填满 `kk`（默认 8，最大 50）个结果后 `break`，**第二轮永远不再执行**；
- 结果：**所有标题被判 poor 的文献，在任何查询下都不可返回**（只要语料中有 ≥k 条非 poor 结果）。

**影响面（当前索引实测）**：

| 项 | 数量 |
|---|---|
| 被判 titlePoor 的文献 | **60 / 835 篇** |
| 涉及块数 | **4,023 块**（占索引 6.8%）|
| 其中 AIC 翻译系列 | AIC2016–2023 **8 篇 / 1,081 块**（色彩研究核心资料）|
| 其他 | `toshi01kondo`、`20010-04-010`、`document`、`main`、`55908383 zh` 等扫描件/孤儿 PDF |
| 受影响金标查询 | **6 / 75**（AIC2017/2018 各 2 条 + `200000509727...` 2 条）|

**佐证**：查询「受访者是否将研究中的颜色解释为治疗色？」官方模拟 rank=1，插件真实接口返回的 50 条里**完全没有**目标文献（`AYZJLH4P`，194 块，标题 `AIC2017翻译`）。

**影响量化（官方 vs 插件真实接口，hit@5 判定不同的 6 条查询）**：

| 查询 | 官方 rank | 插件真实 rank | 目标标题 | titlePoor |
|---|---|---|---|---|
| 受访者是否将研究中的颜色解释为治疗色？ | 1 | 未命中 | AIC2017翻译 | 是 |
| 多功能教室如何整合储物和教学功能？ | 1 | 未命中 | 200000509727... | 是 |
| 医疗保健 色彩 调色板 研究受访者 理解差异 | 1 | 未命中 | AIC2017翻译 | 是 |
| 多功能教室 智慧空间 储物功能 紫外线消毒装置 新风 | 1 | 未命中 | 200000509727... | 是 |
| 景观空间 开敞性 亲水性 达可达性 安全感 | 1 | 7 | （正常标题）| 否 |
| 儿童友好城市 研究 实践 对比 国内外 | 1 | 6 | （正常标题）| 否 |

→ **6 条差异中 4 条由 titlePoor 造成**（修复后插件真实 R@5 预计 **82.67% → ~88%**），另 2 条来自插件查询后处理与模拟排名的其他差异（待查，量级 +2.7pp）。


## 七、建议

| 优先级 | 事项 |
|---|---|
| **高** | 修 `titlePoor` 两轮循环：要么第一轮给 poor 标题留配额（如 `kk` 的 20%），要么去掉跳过、改为排序时轻惩罚；修完用同一套 75 条金标 + 插件真实接口回放验证（目标：插件真实 R@5 回到 ~90%）|
| 中 | reranker 暂缓；若将来做，方向是「GPU + 多语言 reranker（bge-reranker-v2-m3）+ 只重排 top-5」，且必须先用本报告的通过标准复核 |
| 低 | 把「插件真实接口回放」纳入日常回归（本次就是通过它发现 bug 的）|
