# Zotero 检索索引插件 · 团队分发包（v0.1.23）

> 一句话：给本地 Zotero 文献库建**带页码的段落索引**，让 AI agent 按需取相关段落（而不是读整篇全文）。
> 本机实测：同 6 个研究问题，字符消耗降到约 **1/16**，质量分 **83 vs 58**（满分 90）。

---

## 包里有什么

```
retrieval-index-0.1.23.xpi   插件安装包（未签名）
index\                       建好的索引（<块数> 块 / <篇数> 篇 / 1024 维 bge-m3）
  chunks.json                段落块（带页码）
  vectors.b64                int8 量化向量
  meta.json                  统计与指纹
  ocr\                       OCR 旁路文本（12 篇扫描件，保留真实页码）
index-manifest.json          文件 SHA256 + 索引指纹（校验用）
verify_install.ps1           装完一键自检
deploy_index.ps1             自动部署索引（可回滚）
使用说明-团队分发.md          本文件
```

**前置条件**：Zotero 7+（我们在 Zotero 10.0.6 上测试）；你已加入 **SIT2023** 群组并在 Zotero 里完成同步（索引里的条目 key 来自该群组，未同步会检不到）。

## 三步安装

### 1. 允许安装未签名插件

Zotero → 设置 → 高级 → 配置编辑器，搜索 `xpinstall.signatures.required`，设为 `false`。
（或写进 profile 的 `user.js`：`user_pref("xpinstall.signatures.required", false);`）

### 2. 安装插件

Zotero → 工具 → 插件 → 右上角齿轮 → **Install Plugin From File…** → 选 `retrieval-index-0.1.23.xpi` → **重启 Zotero**。

> 把 xpi 丢进目录不会被扫描，必须走「从文件安装」。

### 3. 部署索引

**先关闭 Zotero**，然后在 PowerShell 里执行（在解压后的目录中）：

```powershell
# 预览：只检查目标位置，不写入
powershell -ExecutionPolicy Bypass -File .\deploy_index.ps1

# 正式写入（会自动把已有索引备份成 retrieval-index.bak-<时间戳>）
powershell -ExecutionPolicy Bypass -File .\deploy_index.ps1 -Force
```

启动 Zotero，再跑自检：

```powershell
powershell -ExecutionPolicy Bypass -File .\verify_install.ps1
```

看到 `PASS` 全绿即成功；任一项 `FAIL` 会打印排查建议。

## 用起来

装好后插件在本机 `127.0.0.1:23119` 提供接口：

```bash
# 检索（返回 {evidence, results}，每条带标题/页码/来源）
curl "http://127.0.0.1:23119/retrieval/search?q=儿童色彩偏好&k=8"

# 给 agent 自举使用协议（提示词模板 + evidence 判读规则）
curl "http://127.0.0.1:23119/retrieval/protocol"

# 状态 / 诊断
curl "http://127.0.0.1:23119/retrieval/stats"
curl "http://127.0.0.1:23119/retrieval/ping"
```

> **Windows 上访问本机服务要加 `--noproxy '*'`**（如果有系统代理），否则会被代理拦住。

把 `curl /retrieval/protocol` 的内容作为 agent 的使用协议贴进提示词，效果最好：同证据 A/B 里协议组 **6:0** 胜、总分 86.5 vs 73.0（满分 90）。

## 重要注意事项

1. **索引不会自动更新，按「每月全量快照」更新**：本包是 <快照日期> 的快照，之后群组新增文献本地检索不到。
   每月会发一个新版包（同名 zip，日期不同）；更新方法：**关闭 Zotero → 解压新包 → 重新跑一遍 `deploy_index.ps1 -Force`**（会自动备份旧索引，可回滚），无需重装插件。
   分发渠道：所内私有网盘 / 群文件（**不要公开上传**，见第 3 条）。
2. **建议关掉自动增量**：如果你没装 Ollama（向量模型），启动 90 秒后插件会自动跑增量，可能写出缺向量的块。
   配置编辑器设 `extensions.zotero.retrieval.autoIncremental` = `false`。
   （装了 Ollama 并 `ollama pull bge-m3` 的可保持开启。）
3. **隐私**：索引包含文献正文与标题，**只在课题组内部流转，不要上传公开仓库/公开网盘**。
4. **页码是 PDF 物理页序**，不是印刷页码（封面/罗马数字页会有偏移）。
5. 未 OCR 的扫描件检索不到；本包已含 12 篇中文扫描件的 OCR 文本。
6. 检索接口只读，不会修改你的 Zotero 库。

## 常见问题

| 现象 | 处理 |
|---|---|
| 装插件报「可能不兼容」 | 多半是 `xpinstall.signatures.required` 没设成 false，或 Zotero 版本过低 |
| `ping` 连不上 / 404 | 插件没加载成功：重启 Zotero，看 工具→插件 里是否有 Retrieval Index 且已启用 |
| `stats` 显示 chunks=0 | 索引没部署到正确位置，或没重启 Zotero；跑 `verify_install.ps1` 看具体项 |
| 检索全无结果 | 群组库没同步（条目 key 对不上）；先在 Zotero 里同步 SIT2023 |
| 请求一直挂着不返回 | 历史坑：插件接口若报错可能挂起；先看 `ping`，再重启 Zotero |
| 想回滚 | 把 `retrieval-index.bak-<时间戳>` 改名回 `retrieval-index` 即可 |
